# NoAI Music 개인정보처리방침 (초안)

최종 수정: 2026-08-20

## 요약: 아무것도 수집하지 않습니다

NoAI Music 은 어떤 정보도 외부로 전송하지 않습니다. 개발자를 포함한 누구도
사용자의 데이터를 받지 않습니다. 확장이 하는 모든 통신은 사용자의 브라우저와
youtube.com 사이에서만 일어납니다.

## 기기 안에만 저장되는 것

아래 데이터는 전부 브라우저의 확장 저장소(`chrome.storage`)에만 저장되며,
확장을 삭제하면 함께 삭제됩니다.

| 데이터 | 위치 | 용도 |
|---|---|---|
| 설정 3개 (켜기/자동넘김/시드사용) | sync (브라우저 계정 동기화) | 기기 간 설정 유지 |
| 차단·허용 채널 목록 | local | 필터링 |
| 학습된 채널 판정 (채널 ID·이름) | local | 필터링 (유튜브 공시 기반) |
| 걸러낸 개수 통계, 최근 걸러낸 항목 50건 | local | 팝업 표시 |

## 시크릿(익명) 모드

시크릿 창에서 걸러낸 영상의 제목·채널명은 기록에 남기지 않습니다.
걸러낸 개수(숫자)만 집계에 반영됩니다.

## 확장이 유튜브에 보내는 요청

채널이 AI 생성인지 확인하기 위해, 확장은 사용자가 보고 있는 것과 같은 방식으로
youtube.com 의 시청 페이지를 백그라운드에서 열람할 수 있습니다(채널당 1회, 결과는
기기에 캐시). 이 요청은 youtube.com 으로만 가며, 제3자 서버는 존재하지 않습니다.

## 수집하지 않는 것

- 개인 식별 정보, 계정 정보, 시청 기록의 외부 전송: 없음
- 분석(analytics)·광고·오류 수집 SDK: 없음
- 쿠키 생성: 없음
